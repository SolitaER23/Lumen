## 一、这份 PPT 怎么用

`Lumen-Interactive-Demo.pptx` 是 10 页、16:9 的**可点击导览**，不是静态汇报稿。

- 封面右下角「进入互动导览 →」跳到能力地图；
- 第 2 页六张能力卡片分别跳到连接、播放、电台、声音、离线、隐私章节；
- 每个章节左下角「← 返回导览」回到能力地图；
- 每页右下角固定提供「导览 / 上一页 / →」，可以直接顺序播放；
- 每页备注（演讲者备注）内有该页的讲解提示，放映时可打开备注视图；
- 建议在 PowerPoint 全屏放映模式下使用鼠标/触控点击，超链接才会生效。

## 二、逐页文字稿

### 第 1 页 · 封面

**标题：让自建曲库，会呼吸。**

Lumen 是一款面向自建曲库的 Android 音乐播放器。它通过 Subsonic / OpenSubsonic 协议连接你自己的 Navidrome，把播放、歌词、评分、离线下载与端侧声音分析收进一个安静、有呼吸感的界面。

它不是另一个云端音乐平台，而是“你的音乐，你的服务器，你的设备”这一主张的客户端实现。

### 第 2 页 · 一页看懂 Lumen

六个能力入口：

1. **连接私有曲库**：Navidrome / OpenSubsonic，多账号，Keystore 加密；
2. **播放体验**：波浪进度、歌词跳转、评分、收藏、下载；
3. **氛围电台**：18 个场景，基于 521 维声音特征的连续播放；
4. **声音类型**：11 个视觉家族驱动全局背景，迷你条显示更细子标签；
5. **离线与随身**：边下边播、整张/单曲下载、缓存与状态恢复；
6. **隐私与交付**：端侧推理、强制阅读、release 签名与更新渠道。

这一页是互动入口，点击卡片即可进入对应章节。

### 第 3 页 · 连接你的私有曲库

Lumen 不提供中心化账号，也不托管曲库。用户填入自己的服务器地址、用户名与密码，直接连接 Navidrome / OpenSubsonic。

关键设计：

- 支持保存多个服务器账号，随时切换；
- 密码与统计 Token 使用 Android Keystore 加密；
- 用户使用 HTTP 时，登录页会明确提示“连接未加密”，建议在可信网络使用或配置 HTTPS；
- 登录失败可修改地址/账号后直接重新连接，不需要清空应用数据。

截图展示的是专辑页：封面、曲目、播放/随机/下载按钮，以及底部正在播放的迷你条。

### 第 4 页 · 播放，不止播放

播放页把控制、歌词与曲目信息放在同一屏：

- **波浪进度条**：拖动跳转，时间和进度实时反馈；
- **歌词**：逐行滚动，点按某一行可跳转；
- **评分、收藏、下载**：单曲操作不需要离开播放页；
- **后台播放**：MediaSession 通知与锁屏控制；
- 右侧快捷操作保留下载、收藏、播放模式。

这一页的截图来自真机，曲目是《凤阳花鼓》，界面会随封面取色与端侧分析结果变化。

### 第 5 页 · 氛围电台

入口不是普通列表，而是**长按首页左上角「专辑」标签**。

电台使用曲库分析出的 YAMNet 521 维特征、情绪坐标与节拍，从用户自己的曲库中挑选相近曲目，按场景连续播放。当前提供 18 个场景：专注、学习、工作、阅读、夜晚、睡前、清晨、黄昏、通勤、雨天等。

设计上刻意不展示封面，只让专辑名成为大字号主角；页面没有“下一首列表”，只有连续播放、下一首与换一批。

### 第 6 页 · 声音类型，决定背景怎么呼吸

声音类型分两层：

- **视觉家族（11 类）**：钢琴、鼓、人声、环境声、弦乐、贝斯、电子、铜管、木管、器乐、音乐；
- **迷你条子标签**：电钢琴、军鼓、踩镲、小提琴、女声、雨声、合成器、萨克斯等。

背景只使用 11 个视觉家族，保证色调、位置与强度稳定，不会每几秒换一套视觉造成闪烁；迷你播放条则显示更细的子标签，让用户知道“现在听到的是什么”。

所有颜色来自现有 Material Color Utilities / ColorScheme token，不新增独立配色体系。

### 第 7 页 · 离线，也能继续

- 边下边播的流媒体缓存；
- 整张专辑或单曲下载；
- 缓存与下载分开清理；
- 冷启动恢复上次队列、索引与进度，但保持暂停，不自动播放。

下载文件保存在应用私有目录，不依赖云端。

### 第 8 页 · 所有声音，留在本机

端侧分析由 YAMNet + DSP 完成，推理使用 LiteRT 2.4.0；音频不离开设备，也不上传曲库、播放历史或分析结果。

账号密码与统计 Token 使用 Android Keystore 加密；应用不含广告、用户画像、行为分析或崩溃上报 SDK。

首次启动有强制阅读流程：

- 用户协议与隐私条款必须**分别打开**；
- 每个页面必须滚动到最底部；
- 两项都完成后「同意并进入应用」才可点击；
- 未完成时按钮禁用，并明确提示还缺哪一项。

### 第 9 页 · 可交付的软件，不只是 Demo

当前版本 0.50.5 / versionCode 143：

- release 证书签名，APK 提供 SHA-256 校验；
- 官方更新渠道：夸克网盘，提取码 3GF3；
- 用户协议 / 隐私条款强制阅读；
- 16 KB page 兼容，设备端 LiteRT 推理测试通过；
- Android 8.0+、arm64。

这一页强调：除了功能，交付还包括签名、校验、更新、隐私与支持。

### 第 10 页 · 结尾

**把音乐，留在自己手里。**

自建曲库、端侧理解、有呼吸感的播放体验。

联系：bilibili@晓月枫
