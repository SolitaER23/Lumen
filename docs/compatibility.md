# 兼容性说明

## 支持范围

| 项目 | 要求 |
| --- | --- |
| Android | 8.0（API 26）及以上 |
| 目标 SDK | 36（Android 16） |
| ABI | `arm64-v8a`（当前 APK 不含 32 位/x86） |
| 屏幕 | 竖屏；手机优先 |
| 网络 | 可访问 Navidrome / OpenSubsonic；HTTP/HTTPS |
| 存储 | 约 11 MB 安装包，分析/下载另计 |

## 已验证

| 设备/系统 | 结果 | 说明 |
| --- | --- | --- |
| Pixel 10a / Android 16（SDK 36） | 通过 | 安装、同意流程、通知权限、首页、播放页、电台、LiteRT YAMNet 推理冒烟测试 |
| Android 16 KB page size | 通过 | LiteRT 1.4.0 + `graphics-path` 的 `.so` LOAD 对齐为 `0x4000`；Android 16 不再提示 16 KB 不兼容 |

## 尚需验证

- API 26 / 28 / 31 / 33 / 34 / 35 真机；
- Samsung / Xiaomi / OPPO / vivo 等 OEM 的后台限制、通知与下载；
- 低端 arm64 设备上的 YAMNet 分析与长曲目内存；
- 多窗口/分屏、字体缩放、TalkBack；
- 服务器端 Navidrome 不同版本、反向代理与 302 转码。

## 已知限制

- 只发 arm64，32 位设备无法安装；
- HTTP 连接不加密，仅在可信网络使用；
- Android 15 对 `dataSync` 前台服务有每日时长限制，长时间下载可能被系统停止；
- 未登录/未分析时声音类型回退为「音乐」；
- 卸载会清除本机数据，应用不启用云备份。

## 冒烟测试清单

1. 首次启动：同意/拒绝、协议与隐私可打开；
2. 登录：HTTPS 与 HTTP、错误密码、超时；
3. 播放：本地解码、转码兜底、后台播放、通知/锁屏；
4. 下载：单曲/专辑、断网恢复、缓存清理；
5. 分析：YAMNet 推理、段落标签、迷你条子标签；
6. 电台：长按「专辑」进入、切换场景、换一批；
7. 更新：同签名覆盖安装、数据保留；
8. 卸载/清除数据：数据删除与重新引导。
