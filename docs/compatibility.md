# 兼容性说明

## 支持范围

| 项目 | 要求 |
| --- | --- |
| Android | 8.0（API 26）及以上 |
| 编译 SDK | 37.2（Android 17；Compose 1.13 要求 ≥ 37.1） |
| 目标 SDK | 37（Android 17） |
| ABI | `arm64-v8a`（当前 APK 不含 32 位 / x86） |
| 屏幕 | 竖屏；手机优先 |
| 网络 | 可访问 Navidrome / OpenSubsonic；HTTP / HTTPS |
| 存储 | 约 3 MB 安装包（release）/ 约 19 MB（debug），另有在线播放缓存 |

## 已验证

| 设备 / 系统 | 结果 | 说明 |
| --- | --- | --- |
| Pixel 10a / Android 17（SDK 37） | 通过 | 覆盖安装、冷启动、登录与曲库同步、播放、后台通知、条款门禁、搜索 |
| Pixel 10a / Android 16（SDK 36） | 通过 | 安装、同意流程、通知权限、首页、播放页 |

> Android 17 上访问局域网内的自建服务器需要 `ACCESS_LOCAL_NETWORK` 权限，应用会在首次启动时请求；拒绝授权时连接会失败并给出明确提示。

## 尚需验证

- API 26 / 28 / 31 / 33 / 34 / 35 真机；
- Samsung / Xiaomi / OPPO / vivo 等 OEM 的后台限制与通知；
- 多窗口 / 分屏、字体缩放、TalkBack；
- 服务器端 Navidrome 不同版本、反向代理与 302 转码。

## 已知限制

- 只发 arm64，32 位设备无法安装；
- HTTP 连接不加密，仅在可信网络使用；
- 在线播放依赖服务器网络；本地只保留可随时清理的流缓存；
- 卸载会清除本机数据，应用不启用云备份。

## 冒烟测试清单

1. 首次启动：同意 / 拒绝、协议与隐私可打开；
2. 登录：HTTPS 与 HTTP、错误密码、超时；
3. 播放：本地解码、转码兜底、后台播放、通知 / 锁屏；
4. 缓存：歌曲 / 封面 / 歌词缓存清理；
5. 搜索：艺人 / 专辑 / 曲目、历史记录；
6. 更新：同签名覆盖安装、数据保留；
7. 卸载 / 清除数据：数据删除与重新引导。
