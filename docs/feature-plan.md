# YAMNet 功能路线图

基于现有 YAMNet + DSP 分析能力，按「收益 / 成本」分阶段落地；所有分析均在本机完成。

## Phase 1 — 播放体验与情绪可视化（已实施）

| 功能 | 状态 | 落点 |
| --- | --- | --- |
| 智能衔接：按当前曲目 BPM 取一拍长度做淡入淡出 | ✅ | `Playback.transitionMs`、设置 → 外观 → 智能衔接 |
| 近 7 天情绪时间线：按天统计分析量，颜色取当天主导情绪 | ✅ | `MoodStore.recentDays`、心情分析页 |

验收：BPM 已知的曲目切换使用节拍长度；未分析曲目回退设置时长；时间线显示最近 7 天。

## Phase 2 — 曲目标签与筛选

- 在 `MoodAnalyzer` 聚合 YAMNet 521 类 top-K（乐器/人声/现场/掌声/静音/环境声）。
- 存储：新增 `mood_tags(track_id, tag, score)` 表，随分析写入；旧数据无标签时回退情绪。
- UI：暂不展示标签徽标与筛选入口（按需求保持内部可见性）。
- 验收：标签准确率抽样检查；无标签曲目不显示徽标；筛选不阻塞列表。

## Phase 3 — 氛围电台（已实施）

- 已存储 YAMNet 521 维平均分；用余弦相似度 + 情绪/tempo 生成 30 首本地电台；
- 场景预设：专注、夜晚、活力、通勤；种子只参与相似度，不强制重启当前曲目；
- 入口：长按首页左上角「专辑」标签进入；电台页不展示标签与相似队列；
- 曲库索引缓存在 ilesDir/radio_tracks.json，首次构建显示进度；
- 验收：电台可生成并播放；无分析数据时显示引导。

## Phase 4 — 自动化与可视化

- 自动跳过曲末掌声/长静音（可关闭，默认关闭）。
- 睡眠定时：15/30/60 分钟，在低能量段自然淡出后暂停。
- 可视化：背景随音频事件（钢琴/鼓/环境声）切换图形或色调；通知栏显示情绪图标。
- 本地智能搜索：按「适合跑步 / 纯钢琴 / 安静」检索已分析曲目。

## 风险与约束

- YAMNet 是音频事件分类器，不做人声分离；不提供“伴奏/清唱”能力。
- 标签存在噪声，阈值需按个人曲库校准；始终保留 DSP/情绪回退。
- 新增标签与特征需数据库迁移，旧分析结果不自动重算；可在心情页清空后重跑。
