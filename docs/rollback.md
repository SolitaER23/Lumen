# 回滚手册（Rollback）

## 1. 应用回滚

正式包按版本保留在 `dist/`（该目录不入库，只在发布机上保留），安装旧版即可回退：

```powershell
adb -s <serial> install -r dist\Lumen-<旧版本>.apk
```

- 必须使用**同一签名证书**的包，否则只能卸载重装（会清空本机数据）；
- 新版本已移除端侧音频模型与心情分析，回退到 0.89.x 及更早版本不会读取已无用的 `moods.db`；
- 回退后若设备上仍残留旧模型文件，可在系统设置中清除应用数据，或卸载重装。

## 2. 数据回滚

本机持久数据包括账号凭据、曲库缓存、播放历史、统计与播放缓存。应用不启用云备份，
跨版本回滚前请先在「设置 → 关于 → 问题反馈」复制诊断信息并自行记录服务器与账号。

> 卸载或「清除本机数据」会删除上述全部本机数据，且不可恢复。

## 3. 回滚验证清单

| 检查 | 期望 |
| --- | --- |
| 版本号 | `adb shell dumpsys package app.lumen.player | findstr versionName` |
| 启动 | 冷启动进入首页或登录页，无崩溃 |
| 播放 | 选择专辑可正常播放、暂停、切歌 |
| 数据 | 账号与播放历史按预期保留或按选择清除 |
