# Lumen 用户指南

## 系统要求

- Android 8.0（API 26）及以上；
- **arm64-v8a** 设备（当前 APK 只构建 64 位 ARM；32 位设备无法安装）；
- 可访问你的 Navidrome / OpenSubsonic 服务器；
- 首次使用约 11 MB 安装包，离线下载与心情分析会额外占用空间。

## 安装

1. 从发布页下载 `app-release.apk`；
2. 在系统设置中允许当前文件管理器/浏览器“安装未知应用”；
3. 打开 APK 完成安装；
4. 首次启动会先显示用户协议与隐私条款，阅读并同意后进入引导。

> 本应用不通过应用商店分发。请只从发布页下载，并核对发布页给出的 SHA-256。

## 连接服务器

1. 填写服务器地址（如 `https://music.example.com`）；
2. 输入 Navidrome / OpenSubsonic 用户名与密码；
3. 若使用 HTTP，应用会提示连接未加密：仅在可信网络使用，或为服务器配置 HTTPS；
4. 登录后可播放、搜索、下载、分析心情与生成氛围电台。

## 主要功能

- 首页：专辑、艺人、最近、收藏；长按「专辑」标签进入氛围电台；
- 播放页：拖动波浪进度、歌词跳转、评分、收藏、下载、播放模式；
- 端侧分析：YAMNet + DSP，在本机生成情绪、节拍、声音类型与段落标签；
- 动态背景与迷你条：背景按 11 个声音家族变化，迷你条显示更细的子标签；
- 多账号、Navidrome Stat（可选）、离线下载与缓存清理。

## 更新

- 新版本需使用**同一签名证书**覆盖安装；
- 发布页会提供新 APK、SHA-256 与更新说明；
- 当前正式版与早期 debug 签名测试版不能互相覆盖；从测试版切换需卸载重装。

## 卸载与数据

- 卸载会删除账号、播放历史、评分、心情分析、下载与缓存；
- 应用不启用云备份；卸载前请记录服务器地址与账号；
- 设置 → 账号 →「清除本机数据」可在不卸载的情况删除本机数据。

## 常见问题

**安装失败“应用未安装”**  
确认设备为 arm64、Android 8+，并检查是否与已安装版本签名不一致。

**登录失败**  
检查服务器地址是否包含协议与端口、账号是否允许 Subsonic API、HTTP/HTTPS 是否可达。

**没有通知/下载进度**  
在系统设置中允许 Lumen 通知；Android 13+ 首次登录会请求通知权限。

**下载中断**  
Android 15 对后台数据同步有时长限制；保持应用在前台或分专辑下载。

**心情分析很慢**  
分析在本机运行，长曲目需要更久；可只分析部分曲目，或在设置中清理后重试。

**声音类型不准确**  
YAMNet 为通用音频分类，混音、现场与纯音乐可能归为「音乐」或「器乐」；子标签仅供展示。
