# Lumen 用户指南

## 系统要求

- Android 8.0（API 26）及以上；
- **arm64-v8a** 设备（当前 APK 只构建 64 位 ARM；32 位设备无法安装）；
- 可访问你的 Navidrome / OpenSubsonic 服务器；
- 安装包约 3 MB（release，debug 包约 19 MB），不含随包音频模型；离线下载与缓存会额外占用空间。

## 安装

1. 从官方渠道下载最新 APK（当前为 `Lumen-0.89.0.apk`）；
2. 在系统设置中允许当前文件管理器/浏览器“安装未知应用”；
3. 打开 APK 完成安装；
4. 首次启动会先显示用户协议与隐私条款，阅读并同意后进入引导。

> 本应用不通过应用商店分发。官方渠道为夸克网盘与 GitHub Releases（https://github.com/SolitaER23/Lumen/releases ），
> 两者发布的包使用同一签名证书；下载后请核对 `SHA256SUMS.txt` 中的 SHA-256。

## 连接服务器

1. 填写服务器地址（如 `https://music.example.com`）；
2. 输入 Navidrome / OpenSubsonic 用户名与密码；
3. 若使用 HTTP，应用会提示连接未加密：仅在可信网络使用，或为服务器配置 HTTPS；
4. 登录后可播放、搜索、下载与收藏；界面配色与动态背景会跟随当前专辑封面变化。

> **Android 17 及以上**首次启动会请求「查找、连接到附近设备」权限（`ACCESS_LOCAL_NETWORK`）：这是系统对局域网访问的限制，必须允许才能连上局域网内的 Navidrome。误点拒绝后，可在「系统设置 → 应用 → Lumen → 权限」中重新开启。

## 主要功能

- 首页：专辑、艺人、最近、收藏；支持排序与搜索；
- 播放页：拖动波浪进度、歌词跳转、评分、收藏、下载、播放模式；
- 动态背景：五团渐变随主题色缓慢漂移，配色取自当前专辑封面；
- 多账号、Navidrome Stat（可选）、离线下载与缓存清理。

## 卸载与数据

- 卸载会删除账号、播放历史、评分、下载与缓存；
- 应用不启用云备份；卸载前请记录服务器地址与账号；
- 设置 → 账号 →「清除本机数据」可在不卸载的情况删除本机数据。

## 常见问题

**安装失败“应用未安装”**  
确认设备为 arm64、Android 8+，并检查是否与已安装版本签名不一致。

**登录失败**  
检查服务器地址是否包含协议与端口、账号是否允许 Subsonic API、HTTP/HTTPS 是否可达；Android 17 上还要确认已允许「查找、连接到附近设备」（本地网络）权限。

**没有通知/下载进度**  
在系统设置中允许 Lumen 通知；Android 13+ 首次登录会请求通知权限。

**下载中断**  
Android 15 对后台数据同步有时长限制；保持应用在前台或分专辑下载。

**封面取色不准 / 背景色不理想**  
取色来自当前专辑封面；可在「设置 → 外观」关闭或切换配色风格，也可开启每页独立取色。
