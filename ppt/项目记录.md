# Lumen 使用介绍 · 项目记录

**文件**：ppt/index.html（单文件横向翻页 PPT，图片在同级 images/）
**风格**：瑞士国际主义（Swiss Style），主题 IKB 克莱因蓝 `data-theme="ikb"`
**参考**：作品库「统一设计系统 · 瑞士风 PPT」（examples/ppt-swiss/index.html）
**页数**：10 页 · 建议时长 15–18 分钟
**版本**：Lumen 0.92.1（versionCode 229，arm64-v8a / Android 8.0+）

## 页面计划

| # | 页面 ID | 版式 | 任务 |
|---|---|---|---|
| 01 | cover | SWISS-COVER-ASCII | 封面：你的曲库，装进手机 |
| 02 | position | S03 Split Statement | 定位：不是平台，是播放器 |
| 03 | two-ends | S08 Duo Compare | 服务器 / 手机两端分工 |
| 04 | screens | S16 微卡改图片格 | 三张真机截图：首页 / 播放 / 外观 |
| 05 | connect | S11 Horizontal Timeline | 五步接入：装包到开听 |
| 06 | tabs | S19 Four Cards | 首页四个分区 |
| 07 | player | S05 Three Layers | 播放页三件事：波形 / 歌词 / 评分 |
| 08 | numbers | S20 Stacked Ledger | 3 MB / 4 分区 / 2 语言 / 0 上报 |
| 09 | privacy | S09 Dot Matrix Statement | 不收集、不上报、不猜你想听什么 |
| 10 | closing | SWISS-CLOSING-ASCII | 收尾 + 三条建议 |

## 主题节奏

accent → light → light → dark → light → dark → light → light → dark → split(accent+paper)
（无连续 3 页同主题；含 hero light / hero dark 各一页）

## 图片

`images/04-home.png` / `04-player.png` / `04-appearance.png`（1080×2424 真机截图，54KB 容器内等比显示）。
换图请保持同名覆盖，或全局替换 images/ 路径。

## 演讲

按 P 进入演讲者视图，观众窗同步；右下角 B 可切静态（低功耗）。
每页备注按 data-slide-id 存储，重排页面不会串页。
